## What is Consulting Hub?

Consulting Hub provides a centralized, static reference site for collecting and revisiting practical consulting knowledge. Its content is arranged for quick scanning, straightforward linking, and reuse, with no build process required.

The hub can serve as shared internal documentation, a collection of playbooks, or a structured reference library. Related content is connected across the site, making it easier to move between best practices, consulting frameworks, and useful toolkit resources.

## Working with the Hub

Consulting Hub is intended to be a shared destination for internal guidance, best practices, and related consulting resources.

A typical session looks like this:

1. Launch the site in a web browser.
2. Select a reference guide or open the framework library.
3. Use the internal links to move through connected subjects.
4. Modify or add content files as the team’s material changes.
5. Publish the updated static files again after making changes.

Keeping related information together in a consistent structure makes the collection easier for teams to search and use.

## Site Organization

The site is configured through its static pages and content files, not through a build pipeline.

Content and structure are commonly maintained in:

- HTML files containing the primary sections
- Linked resource files used by the reference material
- Navigation items and internal links defined by the site layout

When expanding the hub, use consistent names and paths so existing cross-references continue to work.

## Frequently Asked Questions

**How can I change the content?**  
Update the applicable static pages or linked resources, then publish the revised files.

**Is local use supported?**  
Yes. The site can be opened from the local filesystem or delivered through a basic web server.

**Where is the configuration stored?**  
The page files and linked content contain most of the site’s organization. New navigation or shared layout elements should remain in the site root or in whatever shared includes are being used.

**How should I troubleshoot a broken link?**  
Begin by checking the linked page names and file paths. Also confirm that referenced resources were not moved or renamed without updating their related links.
